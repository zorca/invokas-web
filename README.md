# Invokas Web

Браузерная версия Invokas на React + TypeScript + Vite. Основа — текущая рабочая копия настольного Invokas 0.1.5, включая последние изменения клиентов и реквизитов. Исходный настольный проект не изменяется.

## Запуск

```bash
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Для телефона в той же сети: `npm run dev -- --host 0.0.0.0`, затем открыть адрес компьютера с портом 5173. Для настоящего использования рекомендуются HTTPS и постоянный домен.

```bash
npm run typecheck
npm test
npm run lint
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Разместить **всё содержимое** этой папки на статическом HTTP/HTTPS-хостинге; не только `index.html`. Сервер приложения и SQL-база не требуются. Навигация внутри приложения не требует серверных маршрутов. Шрифты и генератор PDF входят в сборку.

## Данные

Клиенты, счета, позиции, нумерация, настройки и логотип сохраняются в localStorage (`invokas:database:v1`). Суммы хранятся целыми числами в минимальных единицах валюты. Резервная копия — JSON, не SQLite; импортировать `.db` настольной версии напрямую нельзя.

**Данные принадлежат конкретному браузеру, устройству и адресу сайта.** Другой домен, протокол или порт — другое хранилище. Нет синхронизации между устройствами. Очистка данных сайта или приватного профиля удалит записи. Регулярно скачивайте резервную копию на вкладке «Настройки → Данные». Копии содержат персональные данные: храните их безопасно.

localStorage ограничен квотой браузера; при превышении запись отклоняется, старые данные не подменяются. Логотип: PNG/JPG до 512 КБ; изображение уменьшается до 1024 пикселей. Повреждённая база не заменяется пустой автоматически. Запись всей базы выполняется одним setItem; Web Locks координируют вкладки там, где доступны. Без Web Locks избегайте одновременного редактирования в разных вкладках.

## Скачанная страница и ограничения защиты

`file://`, `data:` и прочие протоколы, кроме HTTP/HTTPS, заблокированы. HTML содержит понятное сообщение даже если модуль JavaScript не загрузится. Автономной офлайн-версии и service worker нет.

Можно привязать сборку к точным доменам: скопировать `.env.example` в `.env.local`, задать `VITE_ALLOWED_HOSTS=invokas.lt,www.invokas.lt` и выполнить `npm run build`. Без этого параметра разрешён любой HTTP/HTTPS-хост. Конкретный домен не задан, чтобы локальная разработка оставалась доступной.

**Это ограничение обычного запуска, а не защита от копирования исходников.** Владелец скачанного JavaScript может удалить клиентскую проверку или запустить копию через свой веб-сервер. Надёжное ограничение домена/доступа требует серверной авторизации и переноса существенной функции на сервер. Запрет контекстного меню и отключение инструментов разработчика здесь не используются: они не защищают код и мешают пользователю.

## Проверка браузера

Сценарий `node scripts/browser-smoke.mjs` использует установленный Chrome и отдельный временный профиль, не затрагивая личные данные браузера. Артефакты проверки находятся в каталоге scratch Hermes. Браузерный сценарий требует Windows/Chrome; обычные тесты и сборка к ОС не привязаны.

Коммиты и развёртывание автоматически не выполняются.
